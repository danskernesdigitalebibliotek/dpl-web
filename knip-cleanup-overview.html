Falske positiver — håndteret i konfigurationen

Knip kan ikke se referencer, der kun findes som strenge eller i værktøjskæden. Disse er ikke slettet, men deklareret i knip.json:

  • Webpack-entries via glob: react-appsene bygges fra src/apps/**/*.mount.ts — uden denne entry troede knip, at næsten hele react/src var dødt (332 "ubrugte filer" i første kørsel).
  • _system.scss: injiceres via en @import-streng i postcss.config.js — var millimeter fra at blive slettet. Samme fil refererer postcss-scss som parser (beholdt, ignoreret).
  • SCSS-entries: design-systemets tre buildindgange (base.scss, wysiwyg.scss, admin-base.scss) — knip følger selv @import-grafen derfra.
  • Drupal-biblioteker: JS under cms/web/modules|themes/custom/** indlæses via *.libraries.yml, som knip ikke parser.
  • Genereret kode: orval-/graphql-/SOAP-output eksporterer alt per design og er undtaget.
  • Workflow-binaries: knip forstår ikke defaults.run.working-directory i GitHub Actions (eslint/playwright), og magenta,blue er en fejllæst farveparameter til concurrently.
  • Bevidst beholdt kode: tagges /** @lintignore */, som konfigurationen udelukker — brugt på RenewStatus-medlemmerne (dokumenterer FBS-API'ets statusværdier) og getFirstPublishedManifestation (har en "deliberately kept"-kommentar).
